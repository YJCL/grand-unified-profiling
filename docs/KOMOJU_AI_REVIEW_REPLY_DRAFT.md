追加の確認事項について、下記のとおり回答いたします。

本サービスでは、文章生成および対話の一部に生成AI（Anthropic API）を利用しております。生年月日・出生情報等に基づく占術データの算出および易の卦を立てる処理はプログラムで行い、生成AIは主に、その結果を利用者ごとの文脈に合わせて文章化するために使用しています。

## 1. AIを使用した鑑定である旨の記載

以下のページにAIの利用範囲と安全対策を記載しております。

- AI利用と安全性: https://orba.life/safety
- 利用規約: https://orba.life/legal/terms
- プライバシーポリシー: https://orba.life/legal/privacy

また、通常チャット、今日の鑑定、易、初回プロフィール作成の各入力・利用画面にも、生成AIを使用する旨と、個人情報・センシティブ情報を入力しないよう注意表示を設置しております。

## 2. 過度に断定的・誇張的な表現への対策

生成時の共通ルールとして、未来、健康、生死、合否、恋愛結果、金銭的利益等を断定・保証しないよう制御しています。加えて、生成後の文章を共通ルールで再検査し、治癒・生死・利益等を保証する表現や、重大な決断を命令する表現を検知した場合は、安全な文章へ置き換えます。

鑑定結果は娯楽、自己理解、選択肢の整理を目的とするものであり、重要な判断では現実の情報および有資格の専門家の助言を優先する旨をサイト上に明記しています。

## 3. NGワード制御および入力時の注意表示

自由入力を受け付ける通常チャット、初回プロフィール作成、易では、生成AIへ送信する前に高リスク相談を判定しています。

- 「死にたい」「消えたい」等、自傷・自殺の危険が疑われる場合は、鑑定やAI対話を行わず、119、いのちSOS、厚生労働省の公的相談窓口をご案内します。
- 「病気が治るか」「薬をやめるべきか」等、医療上の予後・治療判断を求める場合は、鑑定やAI対話を行わず、医療機関への確認をご案内します。
- 法律、投資、犯罪、離婚・退職等の重大な判断を含む場合は高リスク領域として分類し、断定や具体的な決定を促さないよう制御します。
- 氏名、住所、電話番号、病歴等、本人を特定できる情報やセンシティブ情報を入力しないよう、各入力画面に注意書きを表示しています。
- メールアドレス、電話番号等の形式を検知した場合は、生成AIへ送る前に伏せ字へ置き換えます。

## 4. AI出力のモニタリング・制御

入力時の事前判定、生成時の共通安全指示、生成後の出力検査の3段階で制御しています。安全ルールが作動した場合は、対象機能、判定分類、適用したルール、日時のみを安全管理ログへ記録し、管理者画面で確認できるようにしています。安全管理ログへ相談文や生成文の原文は複製しません。

運営者が定期的に検知状況を確認し、誤検知・見逃しが確認された場合は判定ルールと表示を見直す運用としています。

確認用の画面および処理概要を添付資料にまとめております。
