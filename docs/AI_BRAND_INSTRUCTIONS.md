# Orba instructions for AI collaborators

Before changing a user-facing surface, read `PRODUCT.md`, `DESIGN.md`, and `docs/BRAND_GUIDE.md`.

1. Preserve all existing API, Prisma, authentication, billing, notification, chat, and calculation behavior unless the task explicitly changes it.
2. Use the official `OrbaMark` component. Never recreate the retired incomplete ring logo.
3. Use `BrandOrb` for a dimensional brand focal point. Do not replace it with a rotating flat image.
4. Keep the Night / Paper / Gold roles intact. Gold is rare and functional.
5. Use Shippori Mincho for one dominant Japanese statement and Noto Sans JP for supporting UI.
6. Keep core navigation labels visible: 今日, 対話, 暦, プロファイル.
7. Respect `prefers-reduced-motion`, keyboard focus, readable contrast, and mobile bottom navigation.
8. Copy should be precise, warm, and non-deterministic.
9. Mark new identity decisions as confirmed, provisional, or expression before treating them as canonical.
